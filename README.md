# Codex MCP orchestration introduction

A small, dependency-free site introducing a Claude-to-Codex repository workflow over Codex's stdio MCP server. It covers responsibility boundaries, the single-writer rule, the operating loop, setup, session lifetime, timeouts, model policy, and sandbox posture.

## Preview locally

Open `index.html` directly in a browser. No installation, local server, or build step is required.
